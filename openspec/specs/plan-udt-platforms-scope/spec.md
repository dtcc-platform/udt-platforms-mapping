# Spec: plan-udt-platforms-scope

## Purpose

Defines the requirements for `plan/udt-platforms/scope.md`, the scope reference file for `udt-platforms` sessions.

## Requirements

### Requirement: plan/udt-platforms/scope.md exists and contains the Type criteria table

The repository SHALL contain a file at `plan/udt-platforms/scope.md`.

The file SHALL contain exactly one classification table with these columns:

- `Type`
- `Definition`
- `Observable Criteria`

The rows SHALL be:

- `platform`
- `framework`
- `module`
- `excluded`

The file SHALL explain that initiatives and projects are tracked separately in the `udt-initiatives` cycle.
