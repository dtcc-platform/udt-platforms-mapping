# Spec: plan-udt-platform-comparison-rubrics

## Purpose

Defines the requirements for `plan/udt-platform-comparison/rubrics.md`, the scoring reference file for comparison sessions.

## Requirements

### Requirement: rubrics.md exists and contains the 12 dimension rubrics

The repository SHALL contain a file at `plan/udt-platform-comparison/rubrics.md`.

The file SHALL contain the 12 dimension and functional-category rubrics used by `act/udt-platform-comparison/prompt.md`.
