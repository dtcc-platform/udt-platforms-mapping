# Spec: plan-platform-dimensions-scoring

## Purpose

Defines this researcher-facing canonical artifact.

## Requirements

### Requirement: Platform dimensions scoring contains comparison rubrics

The repository SHALL contain `plan/platform-dimensions-scoring.md` as the platform comparison dimensions and scoring rubric input.

The file SHALL define the comparison dimensions and scoring expectations used by `act/compare-platforms.md`.

#### Scenario: Researcher opens platform dimensions scoring

- **WHEN** a researcher opens `plan/platform-dimensions-scoring.md`
- **THEN** the platform comparison dimensions and scoring rules are available
