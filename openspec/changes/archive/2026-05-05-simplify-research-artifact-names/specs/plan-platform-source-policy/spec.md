## ADDED Requirements

### Requirement: Platform source policy governs comparison evidence

The repository SHALL contain `plan/platform-source-policy.md` as the source policy input for platform comparison.

The file SHALL define acceptable source types and citation conventions used by `act/compare-platforms.md`.

#### Scenario: Researcher opens platform source policy

- **WHEN** a researcher opens `plan/platform-source-policy.md`
- **THEN** the platform comparison source policy is available
