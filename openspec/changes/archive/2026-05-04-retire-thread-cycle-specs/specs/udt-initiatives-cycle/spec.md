## REMOVED Requirements

### Requirement: UDT initiatives thread maps projects and deployments through broad discovery

**Reason**: The active repository model no longer treats individual threads as cycles. The initiative output contract and broad-discovery behavior are governed by `act-udt-initiatives-prompt` and the new `plan-udt-initiatives-scope` capability.

**Migration**: Use `act-udt-initiatives-prompt` for prompt/output behavior and `plan-udt-initiatives-scope` for the initiative scope input.
