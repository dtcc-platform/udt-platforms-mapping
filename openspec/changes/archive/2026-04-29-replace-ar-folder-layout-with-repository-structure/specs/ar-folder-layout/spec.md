# RETIRE Spec: ar-folder-layout

## Rationale

The baseline structural capability is no longer accurately described by the name `ar-folder-layout`.

Its current contract governs repository structure, canonical phase/thread locations, canonical prompt/output locations, and README explanation requirements for the active workflow.

That contract should remain, but under the clearer capability name `repository-structure`.

## Delta

- retire `ar-folder-layout`
- replace it with `repository-structure`
