# Entity Discovery Recall Benchmark

This file is the recall benchmark for entity discovery sessions. It lists accepted candidates that are useful for checking whether future discovery runs recover known missed or at-risk entities.

**How to use:** Run `act/entity-discovery-benchmark.md` via an AI CLI to check all `observe/entity-discovery-*.md` files against this list.
